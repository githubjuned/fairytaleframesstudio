# Fairytale Frames - Photography & Visual Storytelling Website

A modern, responsive, high-end photography portfolio and service website built for **Fairytale Frames**.

## 🌟 Key Features

- **Sticky Glassmorphism Navigation Bar**: Modern, semi-transparent header with responsive mobile drawer navigation.
- **Unified Branding**: Custom brand logo `/Fairytale frames` and luxury Golden theme (`#D4AF37`).
- **Interactive Pages**:
  - `index.html`: Hero showcase, featured work, and photography story.
  - `works.html`: Portfolio showcase with golden ambient lighting and interactive category filters.
  - `services.html`: Service offerings breakdown (Editing, Videography, Photography).
  - `contact.html`: Contact form, location information, and social connections.
- **CTA & WhatsApp Inquiry Widget**:
  - Redesigned "Hire Me" CTA button with hover animations.
  - Floating Golden WhatsApp button for instant client inquiries (**+91 77094 34402**).
- **Vercel & GitHub Ready**: Clean HTML/CSS architecture prepared for one-click deployment.

## 🚀 Local Running

You can serve the website locally using any HTTP server:

```bash
# Python
python -m http.server 8080

# Node.js npx serve
npx serve .
```

Open `http://localhost:8080` in your web browser.

## 📦 Deployment to Vercel

1. Push this repository to your **GitHub** account.
2. Log in to [Vercel](https://vercel.com).
3. Import the repository and select **Other / Static Site**.
4. Click **Deploy**!
